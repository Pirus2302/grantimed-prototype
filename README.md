# ГрантиМед — прототипы главной страницы

Четыре варианта главной для медцентра ГрантиМед (Минск, ул. Притыцкого, 91).
Первые три — статический HTML без сборки, открывается файлом или с любого
статик-хостинга. Четвёртый — отдельная сборка на Next.js, выложен уже собранным.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Обложка со сравнением вариантов, ссылки внутрь |
| `v1.html` | Вариант 1 — «свой, но чистый» |
| `v2.html` | Вариант 2 — «осовремененный», с оглядкой на lifecity.by |
| `v3.html` | Вариант 3 — «сдержанный вау» |
| `v4/` | Вариант 4 — «максимум движения», собранная сборка Next.js |
| `vrach.html` | Страница врача, `?v=1\|2\|3&id=<врач>` — тема подставляется по варианту |
| `assets/data.js` | Все данные: направления, врачи, цены, контакты, FAQ |
| `assets/render.js` | Сборка общих блоков на всех вариантах |
| `assets/icons.js` | Линейные иконки направлений |
| `assets/motion.js` | Появление блоков, счётчики и параллакс в вариантах 1 и 2 |
| `assets/v3.js` | Появление блоков, параллакс, подбор врача в три шага |

Исходник четвёртого варианта живёт отдельно — `D:/MYDEV/grantimed-getlayers`.

## Что решено в прототипах

**Читаемость.** Главная беда текущего сайта — белый текст на пудровом фоне,
контраст около 1.4:1 при норме 4.5:1. Гамма сохранена, но логика перевёрнута:
пудра работает фоном, текст тёмный, белый живёт только на насыщенном акценте.
Весь текст проверен автоматически на соответствие WCAG AA, базовый кегль 18px —
аудитория 50+.

**Страницы врачей.** Кнопка «Подробнее» на текущем сайте никуда не ведёт.
Здесь карточка открывает страницу врача: специальность, категория, направление,
что делает на приёме, цена консультации и кнопка записи. Сетка рассчитана на
расширение — в конце списка стоит метка под десять новых врачей.

**Сомнология.** Домашняя диагностика храпа и бесплатная апробация СИПАП вынесены
в отдельный флагманский блок. На текущем сайте это закопано абзацем текста.

**Первый экран.** Появились адрес, часы, телефон, оффер и кнопка записи —
сейчас там только логотип.

**Движение.** Есть во всех четырёх вариантах, но разной силы:

- варианты 1 и 2 — блоки мягко появляются при прокрутке (14px, 420мс, лесенка
  по 60мс внутри сетки), числа в цифрах досчитываются, фотография первого
  экрана идёт параллаксом, шапка получает тень после первого экрана;
- вариант 3 — то же плюс подбор врача в три шага и липкая панель записи;
- вариант 4 — движение как главный приём: экран загрузки, появление текста по
  словам, живой фон, две ленты с перетаскиванием — направления и врачи.

Везде анимации выключаются при системной настройке «уменьшить движение», и
везде страница полностью читается без JavaScript-анимаций.

## Вариант 4 отдельно

Собран из шаблона медцентра библиотеки GetLayers (Next.js 16 + React 19 +
three.js) и перекрашен в пудровую гамму клиники: палитра `olive-terracotta`,
положенная на брендовые цвета, шрифт Inter (у шаблонного Google Sans Flex нет
кириллицы). Данные — те же, что в `assets/data.js`.

**Прокрутка в направлениях переделана.** В шаблоне этот блок был перехватом
прокрутки: секция замирала на четыре экрана, а вертикальная прокрутка
пересчитывалась в горизонтальный ход карточек — листаешь вниз, а едет вбок.
Сейчас это обычный слайдер: вниз — страница, вбок — лента, стрелками, мышью,
свайпом или клавиатурой. Заодно убран наезд блока «О центре» на направления:
под ним лента с кнопками была полностью видна ровно в одном положении прокрутки.
Наезд «Заявки на звонок» на врачей остался — он на месте и никому не мешает.

Чем отличается от первых трёх:

- **страниц врачей в нём нет** — это сравнительная сборка, а не равный участник;
- **фотографии врачей** на сайте клиники всего 200×225 пикселей, для крупных
  карточек они подложены на пудровый фон; нужны нормальные портреты;
- **весит ощутимо больше** — WebGL-сцена и шрифты;
- собирается командой `NEXT_PUBLIC_BASE_PATH=/grantimed-prototype/v4 npx next build`
  в исходном репозитории, результат из `out/` копируется сюда в `v4/`.

## Данные

- Цены — с действующего прайса `grantimed.by/czeny/`, в белорусских рублях
- Врачи и их фотографии — с `grantimed.by/vrachi/`, 9 человек
- Контакты, режим работы, FAQ — с текущего сайта

## Заглушки, которые надо заменить перед запуском

- **Фотографии интерьера и сна** — временные, со стоков (Unsplash). Нужны свои
  снимки клиники, кабинетов и оборудования. `assets/photo/reception.jpg` лежит
  запасным вариантом для первого экрана
- **Портреты врачей в высоком разрешении** — то, что лежит на сайте, для крупных
  карточек не годится
- **Форма записи** ничего не отправляет, только показывает подтверждение
- **Карта** — виджет Яндекса по адресу, точку надо привязать к карточке организации
- **Ссылки на соцсети** в четвёртом варианте пустые — клиент не публикует профили
- **Политика конфиденциальности** в четвёртом варианте — страница-заглушка
- Ссылка «Смотреть весь прайс» ведёт на текущий сайт

## Локальный запуск

```bash
python -m http.server 3142 --directory .
```

Четвёртый вариант собран под адрес `/grantimed-prototype/v4/`, поэтому локально
его удобнее смотреть, раздавая каталог на уровень выше:

```bash
python -m http.server 3144 --directory ..
```
